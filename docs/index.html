Built to stay out of the way

Everything the agent needs is already in the window.

No API keys

free-pi Harness drives the signed-in free-pi runtime. No tokens, no base URLs, no .env files.

One window

Chat, tool stream, file diffs, sessions and the daily allowance live in a single monochrome surface.

One process per folder

Each session keeps its own live agent with its own working directory, so switching projects is instant.

Several projects at once

Each session keeps working in the background: switch folders while another agent is still running its turn.

Survives proxy limits

Prompts wait in a global queue instead of colliding with the 429 lane, and a wide context that trips 413 gets an emergency compact or a heavy-image rescue.

Guided first run

The welcome screen installs Node, installs the free-pi runtime and signs you in — no terminal needed.

Screenshots and files

Paste a screenshot or attach a file, and reference project files inline with @.

Diffs, not logs

Every edit arrives as a compact diff card, and the sidebar tracks what changed in the folder.

Install in one line

Open PowerShell and paste this. It installs the runtime, downloads the app and adds a desktop shortcut.
